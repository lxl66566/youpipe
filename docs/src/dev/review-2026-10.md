Campaign-level pitfalls:

- Cargo emits `-C debug-assertions` only when it differs from the default
  implied by the *profile's* opt-level (it is blind to `[build] rustflags`):
  opt-level overrides must live in profile tables, never in profile-blind
  rustflags.
- Enabling the assertion layer (B5) immediately exposed two latent test bugs:
  the reorder alias assert contradicted the deliberate-overflow unit tests
  (invariant is the caller's, assert removed), and an integration test did
  u64 arithmetic that overflow-checks reject.
- The review's literal B4 recipe (`None => break`) is unsafe on the
  unbounded CAS path: a reserved-but-unwritten slot spins `pop` forever and
  UBs `Drop`. Stage-then-reserve instead (see scheduler.md).
- The review's B6 window formula (Σ buffers + Σ workers) is NOT a sound
  span bound: occupancy constrains instantaneous coexistence, not
  cumulative span — measured span ~2M at occupancy ~900 (a preempted worker
  holds one item while everything flows past). The sound ceiling is
  `next_pow2(n)`; occupancy only sizes the preallocation. Span routinely
  reaches 30–60% of n even without pathological stragglers, so growth is a
  normal path.
- loom's `UnsafeCell` is not plain data (model locations must be
  registered): exposing uninitialized slots via `set_len` explodes loom on
  first write — build buffers per-slot under `cfg(st3_loom)`.
- This machine's ordered drain bench is bistable (~29ms vs ~80–150ms
  rounds, same binary, minutes apart). Cross-time criterion comparisons are
  invalid here; use same-binary interleaved A/B (`bench_ab`, under lock).
- This nightly rejects `usize::from(u32)` (E0277) — use integer-domain
  comparisons.
- The review's R-1 one-liner (overwrite with `uninit()`, unconditional
  `assume_init_drop`) has inverted polarity — that double-drops after a
  successful send. Ownership needs an explicit `consumed` flag.
- Visibility downgrades of `ShardedReceiver`/`FinalRx`/`StageSpawn` cascade
  into `private_interfaces`/`private_bounds` lint errors; the correct level
  is a crate-internal module (see handoff/mod.rs).
- Criterion filter regexes anchor loosely: `sync_filter/youpipe_filter_map`
  also matches the `_owned` bench — terminate filters with `/`.
- P-2: ctp must never be the default even where it is fastest — it runs the
  user chain twice, observable to side-effecting closures; defaults keep
  merge's single-pass semantics.
